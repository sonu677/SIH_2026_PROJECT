# 🌾 KRISHI-MITRA AI
### Smart Agriculture Disease Detection & Crop Advisory System

> An AI-powered agriculture platform developed for **Smart India Hackathon (SIH)** to help farmers detect crop diseases early, receive preventive recommendations, and improve agricultural productivity.

---

## 📌 Problem Statement

Crop diseases cause significant losses in agricultural production every year. Many farmers struggle to identify diseases at an early stage due to the lack of expert guidance and timely diagnosis.

**AgriShield AI** aims to solve this problem by providing an intelligent platform that detects crop diseases using Artificial Intelligence and offers preventive measures, treatment recommendations, and agricultural guidance.

---

## 🎯 Objectives

- Detect crop diseases using AI/ML.
- Provide instant disease diagnosis from crop images.
- Suggest preventive measures and treatment.
- Increase crop productivity through early detection.
- Create an easy-to-use platform for farmers.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/AgriShield-AI.git
```

```bash
cd AgriShield-AI
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Backend

```bash
cd backend
mvn spring-boot:run
```

---

## AI Model

```bash
cd ai-model
pip install -r requirements.txt
python app.py
```

---

## Database

Import the SQL file into MySQL.

```sql
database/schema.sql
```

Update database credentials in:

```
application.properties
```
